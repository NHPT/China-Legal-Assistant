版本：`1.0`
制定日期：2026-09-20
生效条件：本文通过以下地址公开且服务开始受控免费公测
拟公开地址：https://legalapi.hackall.cn/privacy

单独告知的跨境处理，运营方将在实施前更新本说明并履行相应程序。

## 适用范围

本说明适用于通过 `legalapi.hackall.cn` 提供的中国法律智能助手远程 MCP 服务，
以及随完整平台包分发的本地程序 `china-legal-local`。用户自行选择的 MCP
客户端、模型服务商或其他第三方服务不由运营方控制，其数据处理活动适用各自
的隐私规则。

当前远程服务只提供法规研究、案例参考、引用核验和确定性计算，不提供云端证据
文件、文书导出或持久化案件工作区。

`china-legal-local` 在用户电脑上读取原始文件并保存案件工作区、证据包和导出
文书，不收集或上传这些本地原始文件，也不建立运营方云端案件库。本地工具返回
的提取文本会进入 MCP 客户端上下文；使用云端模型时，模型服务商仍可能独立处理
这些文本，用户应在提供材料前完成必要脱敏并审查相应服务商的隐私设置。

## 处理的数据

服务可能处理以下数据：

- 用户主动提交的法律检索词、法规名称、条号、案例检索条件和计算参数
- 当前匿名访问产生的临时主体标识和访问结果
- 工具名称、参数字段名、调用时间、耗时和成功或失败状态
- 用量操作名、加权单位、限流结果和配额状态
- 反向代理或安全设施产生的 IP 地址、User-Agent、访问时间、请求路径和状态码

应用运行审计和用量日志不记录工具参数值、响应正文、证据正文或文书正文。

## 禁止提交的信息

远程服务面向脱敏法律研究。请勿提交：

- 身份证件号码、银行卡号、账号密码或认证凭据
- 精确住址、未成年人身份信息或无关第三方个人信息
- 完整证据原文、未脱敏案件材料或依法不得公开的信息
- 国家秘密、商业秘密或未经授权处理的敏感个人信息

需要处理真实证据或敏感案件材料时，应使用 `china-legal-local`，并在向远程
服务或云端模型提供任何提取文本前删除非必要的身份、账户和精确地址信息。

## 处理目的

上述数据仅用于：

- 提供法规、案例、引用核验和确定性计算服务
- 实施身份验证、配额限制和异常使用控制
- 排查故障、维护运行安全和验证审计完整性
- 形成不包含案件正文的容量和服务质量统计
- 履行法律法规要求的安全及合规义务

运营方不将用户提交内容用于训练模型，也不出售用户数据。

## 处理方式

工具参数在完成当前请求所需期间进入服务内存。当前应用不会主动把参数值或响应
正文写入运行审计和用量日志，也不建立远程案件工作区。

远程访问必须使用 HTTPS。当前阶段不要求 API Key；正式开放账号或购买后如启用
独立凭据，凭据不应写入聊天、Skill、公开仓库或问题报告。

## 第三方与基础设施

服务可能使用域名解析、TLS、云主机、网络防护和日志基础设施。具体供应商及
物理部署位置不公开，但运营方应对供应商访问权限进行最小化管理，并通过合同、
权限控制和安全措施限制其处理范围。

用户主动调用官方来源读取功能时，服务会向白名单内的政府或法院网站请求用户
指定的完整 URL。该网站可能接收 URL 路径及查询参数、服务端 IP、请求时间和
User-Agent。不得在官方来源 URL 或查询参数中放入案件事实或个人信息。

用户选择的 MCP 客户端和模型服务可能独立接收用户输入及工具结果。用户应在
使用前审查相应服务商的隐私政策和数据存储设置。

## 保存期限

- MCP 运行审计：30 天
- 用量日志：30 天
- 反向代理访问和错误日志：30 天
- 当前匿名模式不保存账号凭据；未来账号凭据的保存和删除规则将在启用前更新
- 安全事件调查材料：调查结束后最长 180 天

到期数据按轮转和每日删除流程处置。常规公测流程不得通过修改文件时间或
`delete_after` 延长上述期限；法律明确要求采取其他处理方式时，运营方依法
另行处理并记录依据、范围和期限。

## 查询、更正和删除

用户可通过 hackallsec@yeah.net 提交查询、更正、删除、撤回或投诉请求。
运营方将在 15 个工作日内完成身份核验和处理，或说明无法处理及需要延长的
原因。

远程服务不保存案件工作区或证据正文。已进入轮转归档或安全事件调查的数据，
按适用法律、备份周期和最小必要原则处理。

## 安全措施

运营方采取以下措施：

- HTTPS 传输
- 匿名主体限流、请求体限制和边缘访问控制
- Host、Origin、请求体大小和边缘访问控制
- 生产数据库只读访问
- 不含参数值和正文的运行审计
- 最小权限服务账号、日志轮转和备份校验

任何网络服务都无法保证绝对安全。发现疑似泄露或异常访问时，请立即联系
hackallsec@yeah.net，邮件标题注明“安全事件”。
