# 中国法律智能助手安全响应政策

版本：`1.0`
制定日期：2026-09-20
生效条件：本文通过以下地址公开且服务开始受控免费公测
拟公开地址：https://legalapi.hackall.cn/security

## 联系方式

- 运营主体：陕西海科奥斯信息科技有限责任公司
- 安全报告邮箱：hackallsec@yeah.net
- 邮件标题：`[SECURITY] 问题摘要`
- 工作时间：中国标准时间工作日 09:00-18:00，法定节假日除外
- 首次响应目标：2 个工作日
- 初步评估目标：5 个工作日

当前未公开固定 PGP 公钥。报告中不得直接包含未来账号凭据、案件内容、个人
信息、证据原文或可立即利用的大规模攻击细节。确需传输敏感附件时，应先通过
邮件建立双方确认的加密传输方式。

## 适用范围

允许报告与以下目标有关的安全问题：

- `legalapi.hackall.cn` 及其公开 MCP 端点
- 公开发布的 `china-legal-assistant` Skill
- 运营方明确列入测试范围的公开客户端配置和文档

以下目标不在未授权测试范围内：

- 生产数据库、备份、审核归档和内部数据流水线
- 运营方未明确授权的服务器、账号、邮箱和第三方供应商
- 其他用户的请求、配额、日志、数据或未来账号凭据
- 本地用户的证据、文书和案件工作区

## 允许和禁止的测试

在不影响其他用户的前提下，可以进行人工、低频、非破坏性的功能和访问控制
验证。

未经书面授权，不允许：

- 自动化漏洞扫描、目录爆破或高频枚举
- 压力测试、拒绝服务、配额绕过或资源耗尽测试
- 社会工程、钓鱼或针对工作人员的攻击
- 获取、修改、下载或删除其他用户或运营方数据
- 持久化驻留、横向移动或利用问题扩大访问范围
- 公开披露尚未修复的问题和利用细节

## 报告内容

报告应包含：

- 问题类型和潜在影响
- 受影响的域名、路径和软件版本
- 最小化、可重复且非破坏性的复现步骤
- 发现时间；报告者可自愿提供本人用于测试的出口 IP，便于日志定位
- 已采取的保护措施
- 脱敏后的日志、请求 ID 或截图

请不要发送真实案件数据。无法安全脱敏时，先联系运营方确定传输方式。

## 响应流程

运营方收到报告后：

1. 在 2 个工作日内确认收到并分配跟踪编号。
2. 在 5 个工作日内完成初步严重性和影响范围评估。
3. 根据风险确定缓解、修复、回归测试和发布计划。
4. 与报告者协调披露范围和时间。
5. 对依法需要通知的安全事件，按适用法律及时采取告知和处置措施。

实际修复时间取决于问题复杂度、影响范围和第三方依赖。运营方不会要求报告者
隐瞒依法必须披露的事项。

## 凭据泄露

当前匿名阶段不向用户签发 API Key。未来启用账号或购买体系后，发现凭据泄露时
应立即发送邮件并提供主体 ID、发现时间和脱敏后的使用异常。运营方将在确认后
尽快吊销旧凭据，并通过原发放渠道提供替代凭据。日志中不得记录或回传完整凭据。

## 安全港说明

在遵守本政策、保持善意、避免隐私侵害和服务中断的前提下进行的安全报告，
运营方将优先通过协调方式处理。该说明不授权违反法律、访问第三方数据或超出
明确范围的测试，也不构成奖金或报酬承诺。
